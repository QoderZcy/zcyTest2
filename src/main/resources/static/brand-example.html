Anthropic 品牌样式指南

这是一个展示 Anthropic 官方品牌色彩和排版系统的完整示例页面

排版系统

我们使用 Poppins 字体作为标题，使用 Lora 字体作为正文，确保视觉层次清晰且易于阅读。

标题示例

所有标题（24pt 及以上）使用 Poppins 字体，具有现代感和专业性。如果系统未安装该字体，将自动回退到 Arial。

智能字体应用

自动为标题和正文应用合适的字体系统，保持排版一致性和可读性。

颜色系统

使用精确的 RGB 颜色值确保品牌色彩在不同系统中的保真度。

响应式设计

所有组件都经过优化，在各种屏幕尺寸上都能完美呈现。

核心特性

  • Poppins 字体用于标题（24pt 及以上）
  • Lora 字体用于正文内容
  • 自动字体回退机制（Arial/Georgia）
  • 精确的品牌色彩匹配
  • 智能背景色选择
  • 循环使用强调色增强视觉效果

CSS 变量使用示例

通过 CSS 变量轻松应用品牌色彩：

:root { /* 主色调 */ --color-dark: #141413; --color-light: #faf9f5; --color-mid-gray: #b0aea5; --color-light-gray: #e8e6dc; /* 强调色 */ --color-orange: #d97757; --color-blue: #6a9bcc; --color-green: #788c5d; /* 字体 */ --font-heading: 'Poppins', Arial, sans-serif; --font-body: 'Lora', Georgia, serif; }
